# Thermi.Releases

`thermi-releases`, the owner's levers on the update channels (`docs/adr/0008-updates.md`), which `scripts/updates.ps1` runs: `keys` makes the release and backup key pairs, `publish` puts a build's zips on a channel with a rollout and an urgent flag, `promote` takes beta's version to stable, `rollback` withdraws a channel's version, `disable` turns a channel off, `refresh` signs it again before it expires, `status` shows each channel, and `serve` answers a channels folder over HTTP on this PC, for a test build. Each lever writes the channel's next signed manifest into a folder laid out as the server is: `stable.json`, `beta.json`, `zips/<version>/` and `history/`. Core decides every lever (`src/Thermi.Core/Updates/Levers.cs`); this only reads and writes files. Nothing of it ships.
